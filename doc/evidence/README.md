# 本地验证证据目录

本目录中的原始构建/测试日志、机器构建清单、真实调用指标及URL审计文件保留在开发者本机，不随源码上传。即使记录已脱敏，也不将个人使用轨迹作为公共源码文件发布。`.gitignore`只允许此说明入库。

开发状态与逐项结论见上级的`development-status.md`、`acceptance-results.md`、`native-validation-2026-10-22.md`和`fetch-404-diagnosis.md`。这些本地阶段报告链接的原始证据文件在克隆仓库后可能不存在；它们不是仓库缺失的运行依赖，不能以说明文件代替执行证据。

在自己的开发环境按根README执行检查和构建，生成自己的结果。不得提交Key、.env秘密、用户历史/余额、系统凭据、依赖目录或安装包。测试中的合成公开夹具只证明离线代码行为，不代表真实DeepSeek或目标系统验收。
