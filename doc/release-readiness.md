是第一期明确必需范围，尚未完成，不能因为当前设备是Mac而标为不适用：

- PRD第3节：“Windows 与 macOS 均为第一期必交付平台”。
- PRD第15节M1要求两个平台不用命令行完成检索与余额；M3要求Windows与macOS安装包、双平台及两类Mac芯片安装运行记录。

因此当前两种Mac开发包只完成阶段交付，不能认定整个原请求或全部P0已完成。当前没有Windows/MSVC执行环境，也没有Windows安装包。已提供 `scripts/build-windows.ps1`，仅供Windows机器本地检查/构建；未执行、未宣称通过。

## 最小用户步骤与接续顺序

1. **当前Mac原生验收**：用户手动解锁Mac并告知已解锁；本任务不尝试解锁或更改锁屏设置。检查当前应用是否仍隐藏，通过菜单栏打开，再按正常菜单退出并启动最终包；保留未保存密钥草稿，不能直接杀进程。
2. **真实服务验证**：用户仅在应用设置中自行填写已有DeepSeek API Key，保存后主动确认服务说明。无需把Key发给对话。随后执行一个公开主题的两Search/前三Fetch与主动余额查询，记录状态/耗时/次数而不记录Key或余额数值；成功后再安排30次性能样本及竞态场景。
3. **完成第一期平台范围**：提供可用Windows11 x64/MSVC环境及Intel Mac/macOS13基线测试安排，或由对应机器的测试人执行本地脚本与原始清单并提供不含秘密的记录。本任务当前缺少这些环境，未自动购买硬件/服务。
