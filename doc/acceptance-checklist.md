# 技术点快搜首版验收清单

> 当前范围按用户决定取消正文抓取与内置阅读。AC13–17/30–31/37等已改为零Fetch、外链及兼容验收；PV04撤销。旧版完整清单见[归档](archive/acceptance-checklist-before-search-only-2026-10-22.md)，不要把旧正文故障列为新版未完成项。


版本：0.1。日期：2026-10-22（Search-only）。对应 [产品需求文档](./PRD.md)。

以下是待执行的产品验收项，不代表测试已经通过。每次验收记录应用版本、系统及设备、日期、执行人、结果、证据位置与缺陷编号。离线桩响应可验证状态和错误，但必须另行通过真实接口验证。测试文档均使用公开或合成内容。

第一期为 Tauri 2 应用。功能及本地性能验收须分别覆盖 Windows 11 x64、macOS 13 及以上的 Intel 和 Apple Silicon 设备；记录各平台结果，不用单个平台通过代替其他平台。真实接口性能分别记录 Windows 和 macOS 的网络环境。

## 功能与异常验收

| ID | 场景与操作 | 通过条件 |
|---|---|---|
| AC01 | 未配置密钥首次打开 | 有“填写 DeepSeek API Key”入口；可从设置再次进入；配置前的检索词保留，无网络请求 |
| AC02 | 输入、粘贴、遮挡和保存Key | 草稿可显隐，保存不联网；按用户接受明文配置原子保存、限制新文件权限；前端不回填完整已存Key，日志/历史/WebView存储无Key |
| AC03 | 首次启用联网检索 | 明确看到发送内容类型、目标服务和账户计费说明；确认后才请求 |
| AC04 | 快捷键录制、取消、保存、正常和被占用 | 平台名称可读；点击/Tab录制、仅修饰键不提交、Esc/失焦取消、未编辑不写；注册/写失败保留旧绑定，录制不误触旧组合；保存后实际唤起并聚焦；托盘单色明暗可见、冲突时入口仍可用 |
| AC05 | 唤起、收起、失焦和重新唤起 | 不读剪贴板、不自动搜索；输入和已有结果保留；失焦不丢失内容 |
| AC06 | 输入法组词时按 Enter | 仅确认候选词，不提交搜索；组词结束后的 Enter 可以提交 |
| AC07 | 空白、100 字符、101 字符及非 BMP 字符 | 计数一致；空白/超长不请求、不截断；100 字符可提交 |
| AC08 | 直接输入官方高级语法及问号帮助 | 支持site/-site/lang/after/before/精确短语/排除词和短语/多站点OR；显式站点优先、可见提示，引用内文字不覆盖范围；帮助按需开、可复制、Escape/外部关闭回搜索；100输入/128完整查询，不截断 |
| AC09 | 混合范围提交 | 最多两条逻辑 Search，参数与 PRD 一致，每条最多取50条 |
| AC10 | 仅专利范围提交 | 无显式站点时一条定向 Search、过滤GP文献路径；显式site/-site时原q单请求、不强制GP，范围处明示用户站点优先 |
| AC11 | 一个Search快、另一个慢 | 快结果先显示，不等另一Search；全程无Fetch |
| AC12 | 后续结果到达、存在重复文献 | 新候选追加、原卡片不跳动；命中来源保留；A1/B2 不误合并；鼠标和键盘共用选中，普通行点击不打开，上下从当前行/按钮继续，跨批次滚动且不抢输入/弹层焦点 |
| AC13 | 首批1、3、5、10条候选 | 按实际数量显示，Fetch固定0，不出现抓取状态/错误/预览 |
| AC14 | 连续点击结果标题或打开原网页 | 打开默认浏览器中的首次原始URL，不产生Search/Fetch，不创建内置阅读器 |
| AC15 | 点击含查询编码、重复参数和fragment的来源 | 原始URL不重写、不丢参数或fragment；前后端只允许HTTP/HTTPS、host、无userinfo/控制字符；危险协议被阻止 |
| AC16 | 检查标题、摘要及来源展示 | 只显示Search返回字段，不额外总结，不标为已抓取正文或伪造专利信息 |
| AC17 | 复制来源及旧正文记录恢复 | 复制标题/公开号/原始URL；无正文查找/选区复制，旧正文字段不展示、不触发Fetch，不专项迁移删除历史 |
| AC18 | 近底自动显示、重复触发、失败重试、结束及历史复位 | 每批5条已接收结果，不冒充服务器下一页；重复触发合并，不变更顺序/条件，无Search/Fetch；本地渲染失败可重试，结束停止；新查询/恢复历史取消旧回调，兼容按钮可键盘操作 |
| AC19 | 修改草稿、切换范围但不提交 | 在途任务不改变，结果仍标明实际查询；无新增请求 |
| AC20 | 在途任务重复回车及随后提交新词 | 相同任务不重复请求；新词替换旧任务，旧结果不污染新列表 |
| AC21 | 停止后旧Search响应延迟返回 | 停止调度并保留结果，旧响应不更新UI/写回删除记录，不产生任何正文请求 |
| AC22 | 窗口隐藏时请求完成 | 在原预算内完成，不抢焦点、不发通知；重新唤起可查看 |
| AC23 | 托盘退出再启动 | 请求被取消，任务保存为已停止；启动不自动续跑 |
| AC24 | Search返回401/402/400/403/404 | 永久4xx不盲目重试，401/402终止本轮；保留已有结果，402余额入口仅点击后请求 |
| AC25 | 408、429、5xx、网络断开 | 自动重试最多一次，遵守 Retry-After 和任务时限；失败可解释 |
| AC26 | 60 秒截止和重试等待超过剩余时间 | 取消未完成请求，不再调度；不提前忽略服务端等待时间 |
| AC27 | 全部成功无结果、全部失败、部分失败 | 三种情况文案及状态不同；不能把请求失败说成没有相关专利 |
| AC28 | 混合响应里有非法 URL 或缺字段条目 | 坏条目隔离；整体协议坏标来源失败，不伪装为空结果 |
| AC29 | 返回恶意文本、图片标签及危险URL | 按文字转义，无脚本/远程资源自动请求；默认浏览器外链安全协议校验 |
| AC30 | Search响应超过5MiB | 拒绝过大响应并显示Search错误，不伪装为空结果；已取消正文展示/截断要求 |
| AC31 | 恢复含旧正文/reading/失败状态的历史，再主动搜索 | 恢复不联网、不改原始存储对象，显示Search摘要/来源并兼容终态；没有旧正文错误/缓存提示；主动提交新建任务 |
| AC32 | 关闭历史、超过 50 条、超过 30 天 | 新数据是否持久化与设置一致；数量/时间上限正确清理 |
| AC33 | 删除运行中历史项及清空历史 | 先停止对应任务，用户主动删除记录；迟到响应不能复活，不另设正文缓存清理入口 |
| AC34 | 导出内测指标、检查错误日志 | 不包含查询、URL、标题、正文、账户余额、密钥；保留必要计数和耗时 |
| AC35 | Search结果身份与日期不确定 | 不补猜申请人、公开日或法律状态；按实际来源信息展示 |
| AC36 | 在已结束任务重新提交相同词 | 明确新一轮请求，与运行中重复提交行为不同 |
| AC37 | 重复点击、恢复历史和重试计数 | 混合最多4次Search尝试，仅专利最多2次，Fetch永远为0；来源打开/复制/更多不计API尝试 |
| AC38 | Windows x64、Mac Intel / Apple Silicon 安装包在清洁环境安装、运行、卸载 | Tauri 应用在全部目标环境可用；运行环境和签名方案符合发布流程，无需关闭系统防护；窗口缩放及键盘遍历正常 |
| AC39 | 更换密钥、取消编辑、保存失败 | 取消/失败保留原配置；成功更换停止旧检索和余额请求，清空余额及连接状态，迟到响应不回填，不自动请求 |
| AC40 | Key格式、文件缺失/损坏/写失败 | 首尾去空白，拒绝空值/内部控制符；明文配置按用户接受策略保存，原子失败保留旧配置，关闭设置清草稿 |
| AC41 | Key重启加载、已配置及清除 | 本机配置启动自动加载、请求共享内存；不读迁移删除旧钥匙串；清除Key停止请求/清余额但保留历史 |
| AC42 | 检查设置、主流程和发布包范围 | 说明使用用户自己的 DeepSeek 额度；没有支付、套餐、订阅、充值、订单或试用到期解锁功能 |
| AC43 | 平台快捷键、输入复制粘贴与浏览器打开 | Mac Command/Windows Ctrl符合平台；可改全局键，冲突保留托盘入口；没有内置正文查找要求 |
| AC44 | 关闭窗口与退出应用 | Windows 关闭/Alt+F4、Mac 红色关闭按钮/Command+W 收起窗口；托盘/菜单栏退出和 Mac Command+Q 真正退出并取消请求 |
| AC45 | 未配置、首次查看余额、已有快照后再次打开 | 无密钥不请求；有密钥首次点击调用 GET /user/balance；已有快照显示时间，主动刷新才再次调用 |
| AC46 | 返回 CNY、USD 单币种和多币种余额 | 分币种展示总额、赠金、充值余额；不累加总额与明细、不换汇、不将整个账户余额解释为应用专属额度 |
| AC47 | 返回真实零值、is_available=false、空数组、缺字段、无效金额和未知币种 | 零值与失败严格区分；异常响应不显示成零余额；状态为 false 显示账户不可用提示，但不预先禁用搜索 |
| AC48 | 余额查询失败、超时、有无旧快照、401 | 无快照不填 0；有快照标记刷新失败及上次时间；401 不展示旧值为当前余额并提供更换密钥入口；不删除检索结果 |
| AC49 | 余额刷新/429与Search并发 | 余额1在途、10秒、无重试，429遵守等待；Search最多2并发，余额不计混合4次/专利2次Search预算 |
| AC50 | 余额成功但Search失败 | 状态独立，余额不冒充Search可用，失败不预先禁止搜索；Fetch已取消 |
| AC51 | 启动、唤起、打开设置、搜索完成、退出再启动 | 不自动查询余额；退出清空快照；重新查看才查询；不以两次余额差值计算检索费用 |
| AC52 | 存储/日志/指标和外部页面权限 | 余额仅内存，不导出Key/余额；外部网页在默认浏览器，不在应用WebView中执行，不能访问凭据IPC |

## 性能验收

| ID | 测量内容 | 目标 |
|---|---|---|
| PF01 | 100 次热唤起 | P95 ≤300 毫秒，记录实际设备 |
| PF02 | 提交反馈、停止反馈 | 各 ≤100 毫秒，网络阻塞不冻结 UI |
| PF03 | 收到有效响应到首批卡片可交互 | ≤200 毫秒 |
| PF04 | 至少 30 次真实公开主题查询 | 首批资料可点击目标 P50 ≤5 秒、P95 ≤12 秒；包含失败与超时并单列 |
| PF05 | 连续快速替换任务、隐藏唤起 | 无重复调度、旧数据错配或焦点异常 |
| PF06 | 打开余额面板、刷新及网络迟迟不返回时继续搜索 | 100 毫秒内给出操作反馈；余额请求 10 秒内结束或超时，不冻结主界面，不等待余额才开始检索 |

## 检索价值内测

| ID | 验证内容 | 记录方法 |
|---|---|---|
| PV01 | 30 个真实公开技术任务 | 冻结任务及必要限定，记录来源、实际结果和专业用户评价 |
| PV02 | 可用结果质量 | 至少 70% 的任务有一条被认为值得进一步阅读的资料；点击不等于相关 |
| PV03 | 与现有方式比较耗时 | 使用难度相近或交叉安排的任务，目标中位时间下降 30% |
| PV04 | 已取消：Fetch增量价值 | 不适用；用户取消正文后撤销此实验，不作新版未完成门槛 |
| PV05 | 高频使用 | 5 人中至少 3 人一周主动使用 3 天以上；第二周至少 3 人返回 |
| PV06 | Search失败来源与成本 | 记录Search请求状态/耗时和预算，Fetch固定0；估算不作为账单 |

阻断发布的问题包括：泄露密钥或文档内容、摘要冒充原文、虚构来源或位置、新旧任务错配、停止失效、超预算自动请求，以及主流程无法在目标系统完成。性能和使用价值未达到目标时记录原因并决定修复或收缩范围，不把离线功能通过等同于产品价值通过。
